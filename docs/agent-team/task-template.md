## Independent reports

Each reviewer records their profile, timestamp, exact candidate identity, actual commands and exit codes, findings with severity/path/line, raw evidence and unmet requirements. For performance include hardware, thread controls/counts, warm-up/repetitions, individual timings, memory, output equivalence, median/tail variability and agreed budgets. Do not fill cells with sample results.
