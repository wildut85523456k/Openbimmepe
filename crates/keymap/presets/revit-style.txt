Every key sequence the first page gives that is also on the Autodesk page agrees with it.
# Still to be checked against Revit's own KeyboardShortcuts.xml, and Autodesk's downloadable PDF has more. Entries the page labels as the author's custom shortcuts (QQ, BX, SWC) are left out.
# Format: command id <TAB> shortcut # shortcut ... (letters typed one after the other, Ctrl+Z for chords). Users change these in the settings menu; this file is not edited by users.
