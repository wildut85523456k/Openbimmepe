# Default shortcut preset: Revit-style key map.
# Source: https://mashyo.com/keyboard-shortcuts-revit/ (third-party list, read 14 Oct 2026). PARTIAL: that page states it does not list every default.
# To be checked against Revit's own KeyboardShortcuts.xml when available. Entries the page labels as the author's custom shortcuts (QQ, BX, SWC) are left out.
# Format: command id <TAB> shortcut # shortcut ... (letters typed one after the other, Ctrl+Z for chords). Users change these in the settings menu; this file is not edited by users.
# Columns: id, shortcuts, English name (not read by the program)
# The editing, file and modal keys at the end (Ctrl+, Escape, Tab, Space, F1) are the author's knowledge of Revit's own and are not from the page above; check them too.
# Escape cancels, and pressed twice leaves the tool: the program counts the presses, the key map only says which key cancels. Space flips (door swing, hand) while placing.
