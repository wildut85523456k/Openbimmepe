# OpenBIM Icons v0.2 — generator (historical)

> **Note:** The Qt/gallery instructions below are historical and do not apply to the current branch.
> The `manifest.json` and `apps/desktop-qt` project are not present. The approved 3D PNGs in
> `approved-3d/` are the source of truth for the embedded icons; `make_rust_icons.py` derives
> the transparent PNGs in `rust/`.

The `isometric.py` module is currently an empty stub (no isometric icons on this branch). `generate.py` retains simpler 24×24 drawings for all operations.

Source artwork is newly authored and is **not** a copy of Autodesk or other proprietary product assets. Review production licensing before external distribution.
