# Artwork provenance and licensing

The icons described by `generate.py` are newly authored OpenBIM line-art definitions for this repository. **No Autodesk or third-party icon assets are copied, bundled, or redistributed.**

The visual approach uses a 24px line-icon convention similar to common permissively licensed libraries. This does not imply a dependency on Tabler Icons or its licensing. If future contributions incorporate Tabler, Lucide, Material Symbols, or other existing designs, record exact asset provenance, license notice, and changes for each imported file before merging.

Permission to use, adapt, and distribute this original icon set should follow the repository's chosen project license; **the repository should explicitly designate an asset license before redistributing or shipping commercially**. Do not assume MIT applies to the repository as a whole.

Autodesk and Revit are trademarks of their respective owner(s). The project is not affiliated with Autodesk.

## Catalog and generated PNG assets (October 2026)

The statements above about newly authored SVG definitions apply to those SVGs,
not to all PNG assets in this directory. `catalog-source/catalog.png` is the
BIM/CAD catalog supplied by the user for this application. Its original creator
and license are not asserted here. `approved-3d/catalog-provenance.json` records
the exact source hash and extraction coordinates. Common and supplemental icons
were generated with the built-in image generation tool; their prompts and output
hashes are recorded in `generated-common/`. Neither asset class is described as
Autodesk artwork.

The supplemental project-tab symbols in `generated-ribbon/` were also created
with the built-in image generation tool. Their prompts and hashes are recorded
in that directory; command/panel references are listed separately in
`apps/desktop-qt/RIBBON-REFERENCE.md`.
