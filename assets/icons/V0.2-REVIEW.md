# OpenBIM Icons v0.2 — production design review

Status: **generated SVG implementation committed; visual approval and macOS Qt smoke test pending**.

Based on the user's reviewed icon concept (October 2026). These are newly drawn original **vector approximations**, not literal vector traces of the concept-render image.

## Explicit visual decisions

- **Architecture / Model Line:** retain exactly one icon, a simple **blue 2D line**. Exclude the old 3D sloped/ramp-like model-line symbol. Keep a distinct **Ramp** as an inclined slab.
- **Structure / Brace Frame:** retain exactly one labeled **Brace Frame** icon. `brace` is separately represented as an individual diagonal structural member rather than duplicating a framed-X glyph.
- Exclude any unnamed duplicate between Framing and Footing.
- **HVAC:** 3D rectangular duct, elbow/fitting/tee, distinguishable corrugated flexible duct, and a recognizable centrifugal/axial-style fan with rotor blades. Avoid ambiguous flat L-shape placeholders.
- **Plumbing:** all pipe surfaces metallic gray with circular bores; insulation as concentric circular rings; gray pumps and valves; dedicated backflow-preventer assembly.
- **Electrical:** British-style rocker switch and BS 1363 socket (rectangular three-pin), distribution panel with miniature circuit breakers. These are *ribbon illustrations*, not an electrical regional specification or native family geometry.
- **Coordination and common commands:** remain primarily 2D functional symbols where pictorial 3D would reduce clarity.

## Design constraints

48x48 viewBox for the new physical-model icons; legacy common/coordination icons remain 24x24 and are rendered by Qt at matching toolbar size. The approved 3D PNGs in `approved-3d/` are the source of truth for embedded icons; `make_rust_icons.py` derives the transparent PNGs in `rust/`.
Provide light and dark assets, ensure good legibility at 34px ribbon size and avoid Autodesk artwork/trademarks.

## Inspection checklist

> **Historical:** The Qt/gallery instructions below are no longer applicable.
> The `manifest.json` and `apps/desktop-qt` project are not present on this branch.
> Use `cargo test -p openbim-desktop --release` for embedded icon tests and
> `python3 assets/icons/make_rust_icons.py` to regenerate transparent PNGs.

1. Run `cargo test -p openbim-desktop --release` and verify embedded icon tests pass.
2. Open the egui desktop app and review both light/dark themes.
3. In the app choose Light/Dark and verify thumbnails remain legible on ribbon and in Properties.
4. Confirm Model Line is a blue 2D stroke, not a ramp; confirm Ramp stays 3D.
5. Confirm **Brace Frame** is named and unique; no unlabeled duplicate.
6. Confirm pipe vs duct cross sections differ (round vs rectangular), and fan/duct fittings are recognizable.
7. Confirm British socket (BS 1363 rectangular three-pin) and switch match intended market.
8. Review the icons at 1440x900 on Windows; record any rejected icons as named issues.

## Remaining development

- The software-rendered concept sheet is a visual reference, not source geometry. This library is a first independent SVG execution of the approved direction, requiring the user's detailed icon acceptance.
- Commission or refine high-fidelity 3D illustrations if the simple isometric primitives are insufficient at 34–40px.
- Move Qt commands from English labels to stable tool IDs and map every action explicitly. Icons without IDs currently fall back to Component.
- Add screenshots to PR validation and test Linux and Windows.
